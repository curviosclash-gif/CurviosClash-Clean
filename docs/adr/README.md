# Architekturentscheidungen

ADRs halten nur langfristig relevante Entscheidungen fest. Eine ADR bleibt kurz und verwendet dieses Format:

```markdown
# Titel

## Kontext
Warum ist die Entscheidung dauerhaft relevant?

## Entscheidung
Was gilt verbindlich?

## Folgen
Welche wesentlichen Vor- und Nachteile entstehen?

## Test/Absicherung
Wie wird eine Regression automatisch erkannt?
```

Bestehende Entscheidungen werden nicht als Statusprotokoll fortgeschrieben. Eine geänderte Grundsatzentscheidung erhält eine neue ADR, die auf die ersetzte Entscheidung verweist.
