# CurviosClash product icon

`curviosclash-icon.svg` is original geometric artwork created specifically for
this CurviosClash repository on 2026-07-13. It was built from basic vector paths
and colors; no external image, font, logo, model, or Next-repository asset was
used.

`curviosclash-icon.png` and `curviosclash-icon.ico` are mechanical raster
exports of the same design. The ICO contains the standard Windows icon sizes
from 16 through 256 pixels.

This provenance note travels with the editable source so packaging does not
depend on an untraceable third-party asset.
