# Meadow plants

Twelve existing, self-authored plants from the external CurviosClash-Marketplace
nature collections. `manifest.json` records the source package, original folder,
dimensions, triangle counts and SHA-256 hashes of the unchanged files.

Each species retains its editable Blender source, animated main GLB and two static
LOD exports. Blender uses Z-up; the GLBs use Y-up. Materials are self-contained;
no downloaded models, external texture files or Blender libraries are required.

Kirschhain places the main exports as non-colliding decoration and plays their wind
from the existing match animation clock. Static LODs remain available for reuse;
the collection loader currently supports distance hiding rather than per-model
GLB swaps. The assembled million-triangle meadow is deliberately not imported.
